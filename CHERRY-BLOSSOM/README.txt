# 🌸 Cherry Blossom

**Where Every Celebration Blooms.**

Cherry Blossom is an elegant event management website designed to turn celebrations into unforgettable memories through creativity, style, and seamless planning.

## Features
- Elegant and responsive website design
- About Us and Our Story
- Event services showcase
- Interactive image gallery
- Customer reviews
- Contact page

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Home page
- `about/` – About Us page
- `css/` – Stylesheets
- `js/` – JavaScript functionality
- `assets/` – Images and logos
- `gallery.html` – Event gallery
- `services.html` – Services page
- `reviews.html` – Customer reviews
- `contact.html` – Contact page
